# kakeibo2

個人用の家計簿アプリ(PWA)。HTML / CSS / JavaScript だけで動き、サーバーは不要です。データは端末のブラウザ(localStorage)に保存されます。

## 機能

- **入力画面**:支出/収入の切り替え、日付送り、テンキー入力、カテゴリ選択、メモ
- **支払方法**:現金/カードA/カードB(カードは設定で追加・変更可)
- **引落日の自動計算**:カードごとの締め日・支払月(翌月/翌々月)・支払日から計算。土日祝・年末年始(12/31〜1/3)は翌営業日に調整
- **定期収入**:毎月25日の給料など。休日なら前営業日に入金。月ごとの金額変更はカレンダーの入金日をタップ
- **都度収入**:入力画面の「収入」から記録
- **カレンダー**:日別の支出・収入、カード引落(💳)を表示。日付をタップでその日の明細、記録の追加・編集
- **ホーム**:今月の可処分(残り)、1日あたりの目安、今日あと使える額、引落・入金予定
- **支払手段の提案**:今日使うといつ引き落とされるかを比べ、支払いを最も先にできるカードを提案。カードの利用上限を超える場合や、次の給料日より前に引き落とされる場合は優先度を下げ、可処分を超える支出は現金を提案

### 可処分の計算

```
可処分(残り) = 今月の収入(定期+都度) − 貯金目標 − 今月の支出
1日あたりの目安 = 可処分(残り) ÷ 今日を含む月末までの日数
```

カード払いを「使った月」と「引き落とされる月」のどちらで支出に数えるかは設定で選べます(初期値は使った月)。

## GitHub Pages で公開する

1. このリポジトリの **Settings → Pages** を開く
2. **Source** を「Deploy from a branch」、**Branch** を公開したいブランチ(例:`main`)の `/ (root)` にして保存
3. 数分後に `https://<ユーザー名>.github.io/kakeibo2/` で開けます
4. スマホで開き、「ホーム画面に追加」するとアプリとして使えます(オフラインでも動作)

アプリを更新したときは `sw.js` の `CACHE` のバージョン(`kakeibo2-v1` など)を上げると、端末側のキャッシュが新しくなります。

## 開発

```sh
python3 -m http.server 8000   # http://localhost:8000 で確認
node --test tests/*.test.js   # 計算ロジックのテスト
```

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面の骨組み |
| `css/style.css` | スタイル(ダークモード対応) |
| `js/logic.js` | 締め日・引落日・祝日・可処分・支払提案の計算(DOM 非依存) |
| `js/app.js` | 画面の描画と操作、データ保存 |
| `sw.js` / `manifest.webmanifest` | PWA(オフライン対応・ホーム画面追加) |
